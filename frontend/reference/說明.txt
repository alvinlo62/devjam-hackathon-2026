CityTask 單檔離線版
========================================

民眾端.html   大型廢棄物線上申請（民眾申請流程）
班長端.html   調度台（今日路線、任務清單、物品類別組成、調度決策紀錄）

使用方式
--------
用瀏覽器直接開啟即可，不需要架站、不需要網路。
JS 與 CSS 皆已內嵌，兩個檔案各自獨立，可單獨傳送。

關於資料
--------
這兩個檔案沒有後端。前端偵測不到 API 時會自動使用內建的離線展示資料，
因此所有畫面與流程都能完整操作：

  民眾端：可從三個示範案例（彈簧床墊／兩只行李箱／裝潢廢料）走完
          辨識 → 逐題確認 → 資格判定 → 建立案件 → 進度追蹤，
          過程中可用底部輸入列補充或更正。
  班長端：顯示三個行政區共 28 筆展示案件；右上角會標示「離線 Demo fixture」，
          代表目前讀的是內建資料而非後端。

因為沒有後端，民眾端送出的案件不會出現在班長端的案件池——
這一段需要同時執行前後端（pnpm dev）才看得到。
